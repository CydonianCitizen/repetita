# v0.9.2 Interoperabilità & Navigazione Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement full bidirectional Anki `.apkg` export, hierarchical subdecks (`Parent::Child`) with recursive due counts, and a global Card Browser with multi-criteria search, releasing as version `0.9.2+1`.

**Architecture:**
- Pure Dart service `AnkiExportService` generating an Anki-compatible `collection.anki2` SQLite schema in-memory via `sqlite3` and packaging it into a ZIP archive via `archive`.
- Deterministic `DeckHierarchyHelper` decomposing `::` delimited deck names into trees, calculating recursive card/due rollups, and rendering nested/indented decks in `DeckListScreen`.
- `CardsDao.searchCardsGlobal` and `CardBrowserController` delivering fast multi-criteria queries across all decks (text, deck, tag, flag, status) with an ergonomic Material 3 `CardBrowserScreen`.

**Tech Stack:** Flutter, Drift (SQLite), Riverpod, Dart 3, `package:sqlite3`, `package:archive`.

**Spec:** `ROADMAP.md` §11 (Interoperabilità & Organizzazione: §11.1 Export `.apkg`, §11.2 Subdeck gerarchici, §11.3 Card Browser globale).

- Version in `pubspec.yaml` MUST become `0.9.2+1`.
- Zero new external packages: strictly reuse `package:sqlite3`, `package:archive`, `package:file_picker`.
- Zero compiler or linter warnings on `flutter analyze --fatal-infos --fatal-warnings`.
- 100% test pass rate on `flutter test`.
- All user-facing strings fully localized in both `app_en.arb` and `app_it.arb`.
- Voice: Caveman Ultra + Ponytail (terse, minimal bloat, pragmatic).

## Review Focus

1. **Round-trip Anki Export/Import Compatibility**: An exported `.apkg` must be re-importable by Repetita's own `AnkiPackageService` without data loss or exceptions.
2. **Subdeck Cycle and Orphan Safety**: Deck names with leading/trailing `::` or empty components (`A::::B`) must normalize cleanly without infinite loops or crashes.
3. **Card Browser Live Search Debounce & Performance**: Typing in the global card search must not block the UI thread on large collections.
4. **Export Isolation**: Exporting a single subdeck must only include cards belonging to that deck (and optionally its children), not the entire database.
5. **Preservation of Note Models**: Exported reverse cards sharing a `noteId` must share a note ID in Anki's `notes` table so Anki treats them as siblings.
