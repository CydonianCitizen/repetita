# v0.9.3 Media Pipeline & Image Occlusion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implement local media storage with SHA-256 deduplication, image embedding with fullscreen zoom in flashcards, and a full interactive Image Occlusion editor with multi-card sibling generation, releasing as version `0.9.3+1`.

**Architecture:**
- Drift SQLite schema v9 with new `Media` table (`id`, `fileName`, `checksum`, `sizeBytes`, `createdAt`) and `MediaDao`.
- Offline-first `MediaService` computing SHA-256 hashes, deduplicating image files in private app storage (`app_docs/media`), and serving file handles.
- Pure Dart `ImageOcclusionParser` encoding normalized bounding boxes (0.0–1.0) and managing multi-card sibling batches with shared `noteId` for automatic sibling burying.
- Ergonomic Material 3 `ImageOcclusionEditorScreen` allowing drag-to-draw mask rectangles on any picked image, with label annotations and live card count.
- `MediaImageWidget` with tap-to-zoom `InteractiveViewer` and seamless overlay in `FlipCardView` for standard images and hide-all/reveal-one image occlusions.

**Tech Stack:** Flutter, Drift (SQLite), Riverpod, Dart 3, `package:crypto`, `package:file_picker`, `package:path_provider`.

**Spec:** `ROADMAP.md` §9 (Media: §9.1 Pipeline Media, §9.2 Editor & Rendering Studio) & §10.4 (Image Occlusion).

## Global Constraints

- Version in `pubspec.yaml` MUST become `0.9.3+1`.
- Zero new external dependencies (reuse `crypto`, `file_picker`, `path_provider`, `archive`).
- Zero compiler or linter warnings on `flutter analyze --fatal-infos --fatal-warnings`.
- 100% test pass rate on `flutter test`.
- All user-facing strings fully localized in both `app_en.arb` and `app_it.arb`.
- Voice: Caveman Ultra + Ponytail (terse, minimal bloat, pragmatic).

## Review Focus

1. **Deterministic Coordinate Normalization**: Occlusion boxes must use relative 0.0–1.0 coordinates so rendering is identical across mobile portrait, tablet, and desktop 4K windows.
2. **Sibling Integration & NoteId**: Every Image Occlusion card generated from the same note must share `noteId` so sibling burying works out of the box.
3. **Deduplication Reliability**: Importing or pasting the same image multiple times must compute identical SHA-256 hashes and avoid duplicating disk files.
4. **Offline Resilience**: App must gracefully handle missing or corrupted image files with error fallbacks without crashing the study session.
5. **Drift Migration Safety**: Upgrading database schema from v8 to v9 must preserve all existing decks, cards, tags, and review logs without data loss.
