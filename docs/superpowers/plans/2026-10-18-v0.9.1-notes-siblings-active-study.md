# v0.9.1 (Note Model, Siblings & Active Study) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement note-based reverse cards, automatic sibling burying, type-in-the-answer comparison, RTL language support, and timeboxing/auto-advance controls, releasing as version `0.9.1+1`.

**Architecture:** Extend SQLite/Drift schema to version 8 with an indexed `noteId` column on `cards`. Integrate reverse card generation into `CardsDao` and `CardEditorScreen`. Hook sibling burying into `StudySessionController` with deck unbury actions. Build a pure Dart type-in answer differ and RTL detector for `FlipCardView`. Add timeboxing and auto-advance timers into `StudyScreen` backed by `AppSettings`.

**Tech Stack:** Flutter, Drift SQLite, Riverpod, Dart 3.

**Spec:** `ROADMAP.md` §10.1 (Carte Reverse come Note Type), §10.2 (Bury Siblings Automatico), §10.3 (Type-in-the-Answer), §13.3 (RTL Languages), §10.5 (Timeboxing), §10.6 (Auto-advance).
