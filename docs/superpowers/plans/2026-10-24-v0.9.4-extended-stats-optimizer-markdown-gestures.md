# Repetita v0.9.4 Implementation Plan: Advanced Analytics, On-Device FSRS Optimizer, Math/Markdown, Gestures & Home Widget

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement v0.9.4 features for Repetita: Extended Statistics (True Retention, Interval Distribution, Rating Breakdown), Detailed Card Info with S/D/R Stability Curves, Pure Dart On-Device FSRS Parameter Optimizer (Isolate-based), Offline Markdown & LaTeX Math rendering (pure KaTeX), Customizable Touch Gestures in Study, and Native Android Home Screen Widget with Due Count.

**Architecture:** 
- Analytics & Stability: `StatsDao` SQL aggregation queries for true retention and intervals, paired with `StabilityCurveCalculator` to render mathematical memory retention curves $R(t)$ with custom painters.
- Optimizer: Pure Dart optimization engine using binary cross-entropy loss and mini-batch gradient descent running in a background `Isolate` (`compute`), storing calibrated 17-parameter weights in `app_settings` without external cloud dependencies.
- Rendering: Unified `FormattedContentWidget` integrating `flutter_math_fork` for offline KaTeX TeX rendering alongside standard Markdown and existing `media://` and cloze deletion tags.
- Gestures: `StudyGestureController` wrapping `FlipCardView` in `StudyScreen` with configurable swipe and double-tap actions backed by haptic cues.
- Home Widget: Native Android `AppWidgetProvider` updated via a lightweight `MethodChannel` from `HomeWidgetService`, compliant with F-Droid and zero-cloud principles.

**Tech Stack:** Dart 3, Flutter 3.13+, Drift SQLite, flutter_riverpod, flutter_math_fork, Material 3, Android AppWidget framework.

**Spec:** [ROADMAP.md](file:///c:/Users/thoma/Documents/Projects/repetita/ROADMAP.md) (Milestones v0.9.4, v1.4.0, v1.5.0, Spike Ricerca).

## Global Constraints

- 100% offline-first: zero network calls, zero analytics, zero external API dependencies.
- Privacy & security: local compute only; study logs never leave the device.
- F-Droid compliant: zero Google Play Services / Firebase requirements.
- Impeccable design: strict Material 3 theme adherence, dark/AMOLED support, responsive desktop/mobile constraints, zero pixel overflows.
- Ponytail efficiency: minimal code additions, lazy computations, background isolates for heavy math to prevent UI frame drops.
- Backward compatibility: Drift database schema migrations must preserve all existing cards, tags, settings, and review logs without data loss.

## Review Focus

1. **Optimizer Convergence on Small Datasets**: Ensure optimizer safely rejects datasets with insufficient reviews (< 500 reviews) or prevents gradient explosions with parameter bounding.
2. **Isolate Communication & Freezing**: Ensure numerical optimization runs in a background isolate and reports progress without blocking the main Flutter event loop.
3. **LaTeX Math Syntax Resiliency**: Unclosed `$` or malformed TeX expressions must gracefully fall back to plain text rendering without throwing build exceptions.
4. **Gesture Conflict with Scroll & Flip**: Touch gestures must not conflict with vertical scrolling of long card text or accidental swipes during tap-to-flip.
5. **Widget Data Sync Accuracy**: Home widget due count must accurately reflect due cards including subdecks and excluding suspended/buried cards.
